## 00:21 24h 成交量(USDT)排行榜 CSV (超问"涨跌幅接口有没有24h成交量")

- **结论**: 涨跌幅脚本 `meme_short/binance_24h_change_all.py` 用的是 `/fapi/v1/klines`, 存的 `quoteVolume` 是**单根5m K成交额**, 不是24h累计成交量(USDT)。该脚本拉取数据里**没有24h成交量字段**。
- 币安期货 `/fapi/v1/ticker/24hr` 原生直接给 `quoteVolume`(24h USDT成交额)/`volume`(24h base量)/`priceChangePercent`。探针 HTTP 200 可用(代理已恢复/直连通)。
- 新建 `meme_short/gen_volume_rank.py`: 拉 ticker/24hr(contractType=PERPETUAL, 744条), 与 `symbols_usdt_perp.json`(涨跌幅同款宇宙 696币)取交集过滤, 按 quoteVolume 降序, 输出 `data/volume_rank_usdt_perp_{YYYYMMDD}.csv`(列: rank/symbol/quote_volume_24h_usdt/volume_24h_base/price_change_percent_24h/last_price)。
- 结果: 696/696 全命中(0未命中), 输出 data/volume_rank_usdt_perp_20260825.csv。Top: BTCUSDT 168.5亿 / ETHUSDT 140.5亿 / SNDKUSDT 31.6亿 / SOLUSDT 23.9亿 / XRPUSDT 20.3亿 / XAUUSDT 19.4亿 / ZECUSDT 19.0亿。
- **口径提醒**: "24h成交量(USDT)"=quoteVolume(USDT计价); volume 是 base 资产量(如 BTC个数), 非USDT, 排序用 quoteVolume。
