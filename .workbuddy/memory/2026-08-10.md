## 修复 OKX gateway 启动 `RuntimeError: no running event loop`
- 环境：aiohttp 3.13.5 + Python 3.9.12
- 根因：`RestClient.__init__`(rest_client.py:118) 与 `WebsocketClient.__init__`(websocket_client.py:33) 在构造器里同步 `ClientSession()`，新版 aiohttp 要求必须在 running event loop 上下文创建。
- 修复：rest 把 session 创建延迟到 `start()` 内 `run_coroutine_threadsafe(self._create_session(), self.loop).result()`；ws 把 session 创建放进 `_run` 协程开头。
- 影响面：这两个是通用基类，所有继承它们的 gateway（OKX/binance 等）都受益。
- 验证：`py_compile` 通过。重跑 `examples/vn_trader/run_command.py` 即可确认。

## 修 OKXDataService.py 代理 URL 缺 scheme
- 文件：`examples/vn_trader/App/Turtle_crypto/dataservice/OKXDataService.py` 第20行
- 报错：`Proxy URL had no scheme, should start with http:// or https://`

## 修 OKX gateway `50113 Invalid Sign`
- 文件：`examples/vn_trader/gateway/okx/okx_gateway.py` 第330行 `sign()`
- 报错：`401 / code 50113 Invalid Sign`，私有 GET 请求（orders-pending 等）全挂
- 根因：`request.data = json.dumps(request.data)` 对 GET 无 body（data=None）生成 `"null"` 字符串参与签名；OKX 规范要求无 body 时 body 必须 `""`，服务端用 `""` 校验 → 签名不匹配
- 修复：None/空 → `""`；dict/list → `json.dumps`；已是 str 保持（防二次 dumps）
- 验证：`py_compile` 通过。注意另需核对 run_command 配置里 Secret（非 API Key）与 Passphrase 是否填对，填错也会 Invalid Sign
